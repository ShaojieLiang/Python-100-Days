## 课堂笔记

### 1. 算术运算符

常见算术运算符：

- `+`：加法
- `-`：减法
- `*`：乘法
- `/`：普通除法，结果通常是小数
- `//`：整除，只保留商的整数部分
- `%`：取余数
- `**`：幂运算

示例：

```python
print(10 / 3)   # 3.3333333333333335
print(10 // 3)  # 3
print(10 % 3)   # 1
print(2 ** 3)   # 8
```

### 2. 赋值运算符

常见赋值运算符：

- `=`：赋值
- `+=`：加后再赋值
- `-=`：减后再赋值
- `*=`：乘后再赋值
- `/=`：除后再赋值

示例：

```python
x = 10
x += 5  # 等价于 x = x + 5
print(x)  # 15
```

### 3. 比较运算符

比较运算符的结果是布尔值：`True` 或 `False`。

- `>`：大于
- `<`：小于
- `>=`：大于等于
- `<=`：小于等于
- `==`：等于
- `!=`：不等于

示例：

```python
print(3 > 2)   # True
print(3 == 2)  # False
print(3 != 2)  # True
```

### 4. 逻辑运算符

逻辑运算符用于组合多个条件。

- `and`：两个条件都为 `True`，结果才是 `True`
- `or`：至少一个条件为 `True`，结果就是 `True`
- `not`：取反

示例：

```python
print(3 > 2 and 5 < 4)  # False
print(3 > 2 or 5 < 4)   # True
print(not True)         # False
```
