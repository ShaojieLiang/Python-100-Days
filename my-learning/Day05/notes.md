## 今日核心知识

今天学习了 Python 的分支结构，重点是根据条件决定程序执行哪一段代码。

核心内容包括：

- `if`：条件成立时执行对应代码块。
- `if...else`：在两种情况中选择一种。
- `if...elif...else`：处理多个互斥条件。
- 嵌套 `if`：先判断一个条件，再在内部继续判断另一个条件。
- 缩进：Python 用缩进表示代码块，缩进会决定代码是否受 `if` 控制。
- 判断顺序：程序从上到下判断，命中第一个成立条件后，后面的 `elif` 不再执行。
- 多条件判断：使用 `and` 组合多个条件。

## 遇到的问题

### 1. `int()` 不能直接转换小数字符串

输入成绩 `60.0004` 时，代码使用了：

```python
score = int(input('请输入你的成绩:'))
```

结果出现：

```text
ValueError: invalid literal for int() with base 10: '60.0004'
```

原因是 `int()` 只能直接转换整数形式的字符串，例如 `'60'`，不能直接转换 `'60.0004'`。

解决方法：成绩允许小数时，使用 `float()`。

```python
score = float(input('请输入你的成绩:'))
```

### 2. `bool(input())` 不能用来判断是否输入 `y`

错误写法：

```python
vip = bool(input('是否是会员：y/n'))
```

原因是 `input()` 得到的是字符串，只要字符串不是空字符串，`bool()` 的结果就是 `True`。

例如：

```python
bool('y')  # True
bool('n')  # True
```

正确思路是直接比较字符串：

```python
vip = input('是否是会员（y/n）：')

if vip == 'y':
    print('会员')
else:
    print('非会员')
```

### 3. 误以为 `else` 是必须的

今天复盘时曾误以为 `if...elif` 后面必须有 `else`，实际不是。

Python 中以下写法都可以：

```python
if 条件:
    ...
```

```python
if 条件:
    ...
else:
    ...
```

```python
if 条件1:
    ...
elif 条件2:
    ...
```

`else` 是可选的，它表示“前面所有条件都不成立时的剩余情况”。

## 今日重要理解

### `elif` 和 `else` 的区别

- `elif`：继续判断一个具体条件。
- `else`：表示前面所有条件都不满足时的其他情况。

例如：

```python
if score >= 90:
    print('优秀')
elif score >= 80:
    print('良好')
elif score >= 60:
    print('及格')
else:
    print('不及格')
```

最后使用 `else` 比写成 `elif score < 60` 更清晰，因为程序走到最后时，已经知道前面的条件都不成立。

### `elif` 和嵌套 `if` 的区别

`elif` 适合同一个维度的多个互斥结果，例如成绩等级。

嵌套 `if` 适合先判断一个条件，再在这个条件内部继续判断另一个条件，例如会员折扣：

```text
是否会员？
├── 是会员
│   ├── 价格 >= 200
│   └── 价格 < 200
└── 非会员
    ├── 价格 >= 200
    └── 价格 < 200
```
