## 课堂记录

### 1. for 循环和 range()

示例：

```python
for i in range(1, 6):
    print(i)
```

运行结果：

```text
1
2
3
4
5
```

我的理解：

- `range(start, stop)` 包含起点，不包含终点。
- `range(1, 6)` 会依次产生 `1, 2, 3, 4, 5`，不会产生 `6`。
- `range(stop)` 默认从 `0` 开始，例如 `range(5)` 是 `0, 1, 2, 3, 4`。
- `range(start, stop, step)` 可以设置步长，例如 `range(2, 11, 3)` 是 `2, 5, 8`。
- `for i in range(...)` 不是一次性把一组数字放进 `i`，而是每次循环取一个值给 `i`。
- 缩进到 `for` 下面的代码会重复执行；没有缩进的代码只在循环结束后执行。

### 2. 累加器

示例：

```python
total = 0

for i in range(1, 101):
    total += i

print(total)
```

运行结果：

```text
5050
```

我的理解：

- `total = 0` 是先准备一个变量保存累计结果。
- `total += i` 等价于 `total = total + i`。
- `total += i` 必须放在循环里面，才能每次把当前的 `i` 加进去。
- `i` 只有进入循环后才会被定义，不能在 `for` 循环之前使用 `i`。
- `range(1, 101)` 会取到 `100`，不会取到 `101`。

### 3. while 循环

示例：

```python
i = 1

while i <= 5:
    print(i)
    i += 1
```

运行结果：

```text
1
2
3
4
5
```

我的理解：

- `while` 的意思是：只要条件成立，就继续重复执行。
- 每次循环开始前，都会重新判断条件。
- `i += 1` 很重要，它会让变量发生变化。
- 如果忘记更新变量，条件可能永远成立，程序会进入死循环。
- 当 `i` 变成 `6` 时，`6 <= 5` 为 `False`，循环自然结束。

倒序输出示例：

```python
i = 5

while i >= 1:
    print(i)
    i -= 1
```

运行结果：

```text
5
4
3
2
1
```

结束原因：当 `i` 变成 `0` 时，条件 `i >= 1` 为 `False`，所以循环停止。这里不是 `break`，而是条件不成立。

### 4. break 和 continue

`break` 的作用：立即结束整个循环。

示例：

```python
i = 1

while i <= 6:
    if i == 3:
        break

    print(i)
    i += 1
```

运行结果：

```text
1
2
```

我的理解：

- 当 `i == 3` 时，先执行 `break`。
- `break` 后面的 `print(i)` 不会再执行。
- 所以 `3` 不会被输出。

`continue` 的作用：跳过当前这一轮，继续下一轮循环。

示例：

```python
for i in range(1, 6):
    if i == 3:
        continue
    print(i)
```

运行结果：

```text
1
2
4
5
```

我的理解：

- 当 `i == 3` 时，执行 `continue`。
- 本轮后面的 `print(i)` 被跳过。
- 循环没有结束，而是继续执行 `i = 4` 和 `i = 5`。

对比记忆：

```python
break      # 结束整个循环
continue   # 只跳过当前这一轮
```

### 5. 嵌套循环

嵌套循环就是循环里面还有循环。

示例：

```python
for i in range(2):
    for j in range(2):
        print(i, j)

    print("----")
```

运行结果：

```text
0 0
0 1
----
1 0
1 1
----
```

我的理解：

- 外层循环每执行一次，内层循环都会完整执行一遍。
- 内层循环结束后，才会回到外层循环进入下一轮。
- 每次进入新的外层循环，内层循环都会重新从头开始。
- `print(i, j)` 输出两个值，中间默认用空格分隔，不会自动加括号。
- 如果写 `print((i, j))`，因为 `(i, j)` 是元组，才会输出括号。

三角形练习：

```python
for i in range(1, 6):
    for j in range(1, i + 1):
        print("*", end="")
    print()
```

运行结果：

```text
*
**
***
****
*****
```

我的理解：

- 当 `i = 3` 时，内层循环是 `range(1, 4)`。
- `range(1, 4)` 会产生 `1, 2, 3`。
- 所以内层循环执行 3 次，每次打印一个 `*`。

### 6. 初步认识 f-string

课程中的九九乘法表示例用到了：

```python
print(f"{j}×{i}={j * i}")
```

我的理解：

- `f"..."` 是格式化字符串。
- `{j}` 会替换成变量 `j` 的值。
- `{i}` 会替换成变量 `i` 的值。
- `{j * i}` 会先计算，再把结果放进字符串。
- 如果不习惯 f-string，也可以先写成：

```python
print(j, "×", i, "=", j * i)
```

需要注意：

```python
print(j * i =)
```

这不是合法 Python 语法。`=` 主要用于赋值，例如：

```python
result = j * i
```

如果想打印等号，需要把 `=` 当作字符串输出。

## 遇到的问题

- 一开始把 `i` 理解成了整个数据集。
- 后来修正为：`i` 每次循环只保存当前取出的一个值。
- 对 `total += i` 放在哪里不清楚，原因是还没有完全理解循环体的执行过程。
- 曾把 `while` 条件不成立结束理解成 `break`，后来修正为：没有写 `break` 时，是条件变成 `False` 自然结束。
- 对嵌套循环为什么“外层一次，内层全部执行”有疑问，后来理解为：外层循环的一轮内容包含整个内层循环，必须把缩进块执行完才进入下一轮。
- 对 `f"{j}×{i}={j * i}"` 不熟悉，后来理解为：把变量和计算结果放进字符串。

## 报错记录

可能出现的错误：

```text
NameError: name 'i' is not defined
```

原因：

- 在 `for` 循环开始之前使用了 `i`。
- `i` 是循环变量，只有进入循环后才会依次获得值。

解决方法：

```python
total = 0

for i in range(1, 11):
    total += i

print(total)
```

另一个容易写错的语法：

```python
print(j * i =)
```

原因：

- `j * i =` 不是合法表达式。
- 如果要输出等号，需要把 `=` 写成字符串。

正确写法：

```python
print(j, "×", i, "=", j * i)
```

或者：

```python
print(f"{j}×{i}={j * i}")
```
