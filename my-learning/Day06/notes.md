## 课堂记录

### 1. for 循环和 range()

示例：

```python
for i in range(1, 6):
    print(i)
```

运行结果：

```text
1
2
3
4
5
```

我的理解：

- `range(start, stop)` 包含起点，不包含终点。
- `range(1, 6)` 会依次产生 `1, 2, 3, 4, 5`，不会产生 `6`。
- `range(stop)` 默认从 `0` 开始，例如 `range(5)` 是 `0, 1, 2, 3, 4`。
- `range(start, stop, step)` 可以设置步长，例如 `range(2, 11, 3)` 是 `2, 5, 8`。
- `for i in range(...)` 不是一次性把一组数字放进 `i`，而是每次循环取一个值给 `i`。
- 缩进到 `for` 下面的代码会重复执行；没有缩进的代码只在循环结束后执行。

### 2. 累加器

示例：

```python
total = 0

for i in range(1, 10):
    total += i

print(total)
```

我的理解：

- `total = 0` 是先准备一个变量保存累计结果。
- `total += i` 等价于 `total = total + i`。
- `total += i` 必须放在循环里面，才能每次把当前的 `i` 加进去。
- `i` 只有进入循环后才会被定义，不能在 `for` 循环之前使用 `i`。
- `range(1, 10)` 只会取到 `9`，所以如果要算 1 到 10，需要写 `range(1, 11)`。

## 报错记录

可能出现的错误：

```text
NameError: name 'i' is not defined
```

原因：

- 在 `for` 循环开始之前使用了 `i`。
- `i` 是循环变量，只有进入循环后才会依次获得值。

解决方法：

```python
total = 0

for i in range(1, 11):
    total += i

print(total)
```
