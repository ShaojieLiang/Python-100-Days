## 今日核心知识

1. 变量是用来保存数据的名字，例如：

```python
name = 'shaojie'
age = 22
```

2. Python 常见基础数据类型：

- `int`：整数，例如 `22`
- `float`：小数，例如 `3.14`
- `str`：字符串，例如 `'22'`
- `bool`：布尔值，例如 `True`、`False`

3. 使用 `type()` 查看变量类型：

```python
print(type(age))
```

4. 类型转换：

```python
int('8')          # 8
float('8.5')      # 8.5
str(8.5)          # '8.5'
int(float('8.5')) # 8
```

5. 变量命名规则：

- 只能由字母、数字、下划线组成
- 不能以数字开头
- 不能使用 Python 关键字
- 不推荐使用 `print` 这类内置函数名作为变量名
- 变量名要见名知意，但不要过长

## 遇到的问题

1. 一开始把 `study_day = 'day03'` 写成了字符串，而练习要求是数字 `3`。
2. 对 `int('3.14')` 的理解有误，以为结果会是 `3`。
3. 对 `int('年龄')` 有误解，以为变量名或中文文字可以转换成整数。

## 报错原因

- `int('3.14')` 会报错，因为 `'3.14'` 是带小数点的字符串，不是整数形式的字符串。
- `int('年龄')` 会报错，因为 `'年龄'` 不是数字字符串。
- `"年龄：" + 22` 会报错，因为字符串不能直接和整数用 `+` 拼接。

## 解决方法

```python
int('8')              # 正确
int(float('3.14'))    # 正确
str(22)               # 把整数转成字符串
```

推荐写法：

```python
age = 22
print(f"年龄：{age}")
```
