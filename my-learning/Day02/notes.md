### 2. `print()` 函数

`print()` 用于把内容显示到屏幕上，可以输出不同类型的数据，例如：

```python
print("Hello")
print(100)
print(3.14)
print(True)
```

理解到的关键点：

- `print()` 可以输出字符串、整数、浮点数和布尔值。
- 函数参数会先被计算，再传给 `print()`。
- 例如 `print(12 * 8)` 会先计算 `12 * 8` 得到 `96`，再输出 `96`。

### 3. 一次输出多个内容

```python
name = "Shaojie"
age = 23

print("Name:", name)
print("Age:", age)
```

要点：

- 英文逗号 `,` 用来分隔 `print()` 的多个参数。
- `print()` 默认会在多个参数之间加一个空格。
- `print("Age:", age)` 不会报错，因为 `print()` 可以处理不同类型的数据。
- `print("Age: " + age)` 会报错，因为字符串不能直接和整数用 `+` 拼接。

### 4. `sep` 参数

`sep` 控制同一个 `print()` 里多个参数之间的分隔符。

```python
print("Python", "Data", "Science", sep="-")
```

输出：

```text
Python-Data-Science
```

容易混淆的点：

- `sep="***"` 里的 `***` 是字符串分隔符，不是乘法。
- `print(1, 2, 3, sep="+")` 输出的是 `1+2+3`，这里的 `+` 是普通分隔符，不是加法运算。

### 5. `end` 参数

`end` 控制一条 `print()` 结束时输出什么，默认是换行 `\n`。

```python
print("A", end="-")
print("B")
```

输出：

```text
A-B
```

理解到的关键点：

- `end` 不只是“避免换行”，而是指定本次 `print()` 结束时输出什么。
- `end=""` 表示结尾什么都不输出。
- `end=" "` 表示结尾输出一个空格。
- `end="***"` 表示结尾输出三个星号。
- `end="\n"` 是默认换行。

### 6. 注释

注释是写给人看的，不是写给 Python 看的。

```python
# print("Hello")
```

要点：

- `#` 后面的内容会被 Python 忽略。
- 注释可以解释代码意图，也可以临时关闭某行代码。
- 好的注释应该解释业务含义、设计思路或为什么这样写，而不是重复代码本身。

## 遇到的问题

### 1. 把 `sep="***"` 误认为乘法

一开始以为：

```python
print(1, 2, 3, sep="***")
```

因为 `1、2、3` 是整数，所以 `***` 可能表示乘法或重复。

正确理解：

- `sep="***"` 中的 `***` 有引号，是字符串。
- `sep` 只负责作为分隔符，不参与数学运算。
- 输出结果是 `1***2***3`。

### 2. 对数字加不加引号的区别还需要继续巩固

已理解：

```python
1      # 整数 int，可以参与数学运算
"1"    # 字符串 str，表示文本
```

在 `print()` 显示时，两者可能看起来一样；但参与运算时完全不同。

### 3. 对 `end` 的空格细节需要注意

曾预测：

```python
print("A", end="-")
print("B")
```

可能输出 `A- B`。

正确输出：

```text
A-B
```

原因：`end="-"` 只输出一个短横线，不会自动添加空格。

## 解决方法

- 把 `print()` 的参数拆开理解：逗号表示多个独立参数，不是数学运算。
- 看到引号时，先判断它是字符串。
- 区分 `sep` 和 `end`：
  - `sep` 管同一条 `print()` 内多个参数之间。
  - `end` 管这一条 `print()` 结束后输出什么。
- 通过预测输出而不是直接运行，加深对执行顺序的理解。
